# LifeOS

## Что

LifeOS — мобильный AI-дневник для саморазвития. Пользователь пишет или записывает мысль голосом, получает структурированный конспект, эмоции, темы, вопрос для размышления и небольшой следующий шаг.

## Для кого

Для людей 20–40 лет, которым важно лучше понимать своё состояние, формировать привычки и двигаться к целям.

## Экраны MVP

1. Главная: настроение, запись мысли текстом или голосом, быстрый доступ к разделам.
2. Результат AI-анализа: конспект, эмоции, темы, вопрос и следующий шаг.
3. История: сохранённые записи с безопасным удалением.
4. Привычки: создание ежедневных привычек и серии выполнения.
5. Цели и аналитика: прогресс целей и недельная сводка.

## Что не входит в текущий MVP

- Социальная сеть и рейтинги.
- Финансовый учёт и AI-продавец.
- Умные часы, календарь и веб-версия.
- Неограниченный чат с ИИ.

## Технологии

- Expo / React Native.
- Node.js API.
- Supabase Auth и Postgres с RLS.
- OpenRouter для AI-анализа.
- Groq Whisper для быстрой расшифровки голоса на бесплатном тарифе (ключ хранится только на сервере LifeOS).
